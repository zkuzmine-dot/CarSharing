# Каршеринг: императивное ООП («до»)

Учебное приложение для семинара «Выделение вычислений из действий» и
«Улучшение структуры действий». Здесь намеренно собраны типичные зависимости
и смешение обязанностей, которые можно будет постепенно устранить на
последующих этапах. Несмотря на это, приложение работоспособно, а его
наблюдаемое поведение закреплено тестами.

## Требования

- Python 3.12+
- Для разработки: `pytest`, `freezegun`, `mypy`
- Код приложения использует только стандартную библиотеку.

Установка и запуск из корня репозитория:

```powershell
python -m pip install -e ".[dev]"
python main.py
python -m pytest
python -m mypy
```

Все начальные данные создаются в памяти при старте. Приложение не использует
файлы данных, базу данных, сеть или фреймворки.

## Учебные намеренные проблемы

- `Trip.finish` считает цену, списывает деньги, меняет машину, печатает чек и
  изменяет статический счётчик.
- Методы самостоятельно читают `datetime.now()`, а коэффициент спроса —
  глобальный `Config` и `random.random()`.
- Сервис и объекты напрямую меняют баланс клиента и статус автомобиля.
- `Booking.cancel` сам читает часы, изменяет состояние и сигнализирует об
  ошибке исключением.
- `Customer.trips` отдаёт наружу изменяемый список.
- Тарифы создаются в нескольких местах; расчёты для дня и ночи дублируются.

Это не рекомендуемая архитектура для production. В последующих этапах семинара
можно выделить чистые вычисления, явные входы и выходы и иммутабельные данные,
сохраняя внешне наблюдаемое поведение, зафиксированное тестами.

## Операции предметной области

Демо запускает регистрацию клиента и проверку прав, поиск ближайшей свободной
машины, 15-минутную бронь, отмену с бесплатным окном в 5 минут и комиссией,
начало и завершение поездки, расчёт дневной/ночной стоимости с километрами и
простое, скидки по промокоду и баллам, проверку парковки и штраф, пополнение
и списание баланса, блокировку должника, перегон машины и месячную выписку.

Начальный пароль/аккаунт не требуется: CLI служит детерминированной учебной
демонстрацией.
