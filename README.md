# Каршеринг: учебный рефакторинг

Учебное приложение для семинара «Выделение вычислений из действий» и
«Улучшение структуры действий». Исходный императивный вариант сохранён в
коммите `initial`; последовательные изменения демонстрируют рефакторинг,
закреплённый характеристическими тестами.

## Требования

- Python 3.12+
- Для разработки: `pytest`, `freezegun`, `mypy`
- Код приложения использует только стандартную библиотеку.

Установка и запуск из корня репозитория:

```powershell
python -m pip install -e ".[dev]"
python main.py
python -m pytest
python -m mypy
```

Все начальные данные создаются в памяти при старте. Приложение не использует
файлы данных, базу данных, сеть или фреймворки.

## Текущие архитектурные решения

- Чистые вычисления сгруппированы в `carsharing/calculations.py`; время,
  параметры спроса, тариф и скидочные параметры передаются явно.
- Сущности являются `@dataclass(frozen=True)`; связанные коллекции — кортежи
  идентификаторов. Сервис обновляет состояние через `dataclasses.replace`,
  оставляя уже выданные объекты неизменными.
- `Settings`, источник времени и генератор случайных чисел передаются сервису
  при создании; изменяемого глобального объекта настроек нет.
- Тариф и поездка создаются фабриками `Tariff.create` и `Trip.start`.
- Дневная и ночная цена рассчитываются общей функцией
  `calculate_cost(tariff, period, ...)`.

## Операции предметной области

Демо запускает регистрацию клиента и проверку прав, поиск ближайшей свободной
машины, 15-минутную бронь, отмену с бесплатным окном в 5 минут и комиссией,
начало и завершение поездки, расчёт дневной/ночной стоимости с километрами и
простое, скидки по промокоду и баллам, проверку парковки и штраф, пополнение
и списание баланса, блокировку должника, перегон машины и месячную выписку.

Начальный пароль/аккаунт не требуется: CLI служит детерминированной учебной
демонстрацией.
